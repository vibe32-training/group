# 모둠 만들기

학생 이름을 입력하고 모둠 수 또는 모둠별 인원을 선택해 무작위로 편성하는 반응형 웹 앱입니다.

## 실행

필요한 도구: Python 3, Node.js 18 이상

PowerShell에서 프로젝트 폴더로 이동한 뒤 로컬 웹 서버를 실행합니다.

```powershell
python -m http.server 4173
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 열어 사용합니다. 서버를 종료하려면 PowerShell에서 `Ctrl+C`를 누릅니다.

## 테스트

```powershell
npm.cmd test
```

## 주요 기능

- 줄바꿈 또는 쉼표로 학생 명단 입력
- 모둠 수 또는 모둠별 인원 기준 편성 및 다시 섞기
- 한 줄에 `학생 이름, 학생 이름` 형식으로 입력한 갈등 학생 분리
- 결과 복사, 인쇄, CSV 다운로드
- 저장한 결과를 브라우저에서 불러오고 삭제

동명이인은 이름 뒤에 등장 순번을 붙여 구분합니다. 예를 들어 명단에 두 번째로 나오는 `김하늘`은 `김하늘#2`로 지정합니다. 갈등 관계가 모두 지켜지지 않는 경우에도 가장 나은 편성 결과를 표시하고 경고합니다.

저장 데이터는 현재 브라우저의 로컬 저장소에만 보관되며 서버로 전송되지 않습니다. 브라우저 데이터가 삭제되면 저장 결과도 사라질 수 있습니다.
